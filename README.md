# 📊 Bank Loan Analysis Dashboard

## 📌 Overview

The **Bank Loan Analysis Dashboard** is a data analytics project designed to analyze and visualize bank loan data. The dashboard provides insights into loan applications, funded amounts, repayment amounts, loan status, and customer-related trends.

The project helps transform raw loan data into meaningful visual insights that can support better understanding of **loan performance, customer behavior, and financial trends**.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze overall loan application trends.
* Track total funded and received loan amounts.
* Understand loan approval and repayment patterns.
* Analyze loan performance based on different categories.
* Identify trends in loan applications over time.
* Compare good and bad loan performance.
* Provide an interactive dashboard for easy data exploration.

---

## 📊 Key KPIs

The dashboard focuses on important Key Performance Indicators (KPIs), including:

* **Total Loan Applications**
* **Total Funded Amount**
* **Total Amount Received**
* **Average Interest Rate**
* **Average Debt-to-Income Ratio (DTI)**
* **Good Loan Applications**
* **Bad Loan Applications**
* **Good Loan Funded Amount**
* **Bad Loan Funded Amount**

---

## 📈 Dashboard Insights

The dashboard provides analysis of:

### Loan Applications

Analysis of the number of loan applications and how they change over time.

### Funded Amount

Analysis of the total amount of money funded through approved loans.

### Amount Received

Analysis of repayments received from borrowers.

### Loan Status

Analysis of loans based on their current status, such as:

* Fully Paid
* Current
* Charged Off

### Good vs Bad Loans

Comparison of performing and non-performing loans to understand overall loan portfolio quality.

### Customer Analysis

Analysis of loan characteristics based on factors such as:

* Employment Length
* Home Ownership
* Loan Purpose
* Loan Grade
* Loan Term
* Annual Income
